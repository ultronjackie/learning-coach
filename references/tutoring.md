# 分层提示、复述与未见迁移

计分题先按 [正式课程](formal-course.md) 看政策。下面每一步都返回一个动作。动作不写出解答，也不把这一步记成独立掌握。学习者随后做对时，用该动作给出的 `assistance` 去写 [证据记录](evidence.md)。

## 计分题上先挡住成稿

学习者直接要答案或提交稿，动作为 `refuse_graded_completion`。不返回解答。政策还不是 `verified` 时，下一步是 `request_policy`：请学习者贴出已经读到的规则原文。政策已核实且明确不允许一般概念时，停住。其余情况可以接着讲一般概念，但仍然不写提交稿。已核实的原文如果允许答案，照实说明允许，同时仍然拒绝代写。

还没有看到学习者自己的尝试时，提示、讲解或继续都先 `restate_attempt`：请学习者写下已经试过的一步。不因为停顿就给答案。

## 已有尝试之后的层次

计分题在政策还未核实前，不进入针对该题的层次。未知、冲突、缺少政策，或只标了已核实却没有原文，都一样。模式写成自学也不能例外。这时只做两件事：`request_policy`，以及学习者要概念时的 `explain_general_concept`。不给 `orient_concept`、`strategic_hint`、`partial_structure` 或 `analogous_example`。

政策已核实，并且原文明确允许不含解答的提示之后，一层只走一步：

1. `orient_concept`：指出相关概念，不把概念套进答案。帮助记为 `hint`。没有核实过的页码就不写页码。
2. `strategic_hint`：一个问题，或点出缺的条件名称。帮助记为 `hint`。
3. `partial_structure`：只给论证或程序的形状，扣住关键推断。帮助记为 `hint`。
4. `analogous_example`：还要原文明确允许另一道例题。必须是另一道题。帮助记为 `worked_example`。
5. `request_teachback`：请学习者用自己的话复述概念、条件和这一步为什么成立。这一步本身不提供新信息。

原文明确不允许提示时，层次收成一般概念（若也未被禁止）然后复述，不给策略提示。原文没写允许，就不当成允许。

非计分的自学练习仍按：概念定位、一条策略提示、扣住关键推断的结构、另一道例题、复述。学习者明确要完整讲解，并且该题不是计分题、模式是自学：给 `fuller_explanation`，帮助记为 `answer_shown`。这保留原来的“明确要求时可以讲完，但必须记下帮助”。计分题即使开在自学模式里，也不走完整讲解，也不走上面的针对题目的提示。

## 复述之后

复述完成而迁移题还没出：`assign_unseen_transfer`。这道题必须没出现过，并且不是那份计分提交。出题本身不是帮助。然后停下来等真实作答。

复述成功只说明学习者能讲出刚才的内容，等级不超过已接触。独立完成要等这道未见迁移题在没有帮助时做对。延迟保持还要再等一个更后的本地日、另一道未见题。层次用尽就 `stop_and_wait`，不要为了推进改出计分题的解答。

同一条计分题上给过 `hint`、`worked_example` 或 `answer_shown` 之后，该题的成功最高是辅助完成。
