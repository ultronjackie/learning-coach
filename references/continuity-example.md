# 示例：数学分析中的连续性怎样学

这是教材主导工作流的示例，不是某位学习者已经完成的课程。正式使用前先诊断基础、确认教材与目标；不要把整份示例一次性当讲义发给新手。

## 诊断如何影响路线

先少量逐题检查：能否读懂“任意/存在”的顺序，能否说明数列收敛，能否用简单不等式控制误差。初学者尚未学这些内容时先补必要基础。已经能独立说明和应用时快速通过，不重讲整套基础。

| 实测卡点 | 本课调整 | 后续证据 |
| --- | --- | --- |
| 量词与变量依赖混淆 | 缩短阅读，拆解 ε、δ 与固定点的角色 | 用新表述判断量词顺序与连续性的否定 |
| 会背定义，证明衔接断裂 | 指回所用数列极限或估计，补一个关键步骤 | 在新函数/新序列上独立说明该步骤 |
| 定义、论证均稳，条件迁移弱 | 少复述定义，增加定义域和定理假设的比较 | 给反例或准确说明为什么不能推出结论 |

只记录真实表现。上述行是可选分支，不表示当前用户有这些问题。

## 一次可直接执行的派读示例

采用作者公开的 Jiří Lebl《Basic Analysis》网页版作为演示来源（2026-10-24 核对）：

- **范围**：[§3.2.1](https://www.jirka.org/ra/html/sec_cont.html)，定义 3.2.1 到命题 3.2.2 及其证明结束。网页版不编造页码；纸书/PDF 上课时换成已核实的版次与页码，并区分 PDF 页序。
- **目标**：准确理解点连续，能说明它与函数极限、序列判别的联系。
- **读前问题**：δ 能依赖谁？为什么函数在该点的值必须进入定义？序列判别给证明带来了什么工具？
- **阅读产出**：自己重述定义、标出命题中“聚点”条件的用途，并指出证明中一个你无法说明的步骤。
- **检查点**：读完后先回答一个问题，随后按答案补讲；不提前发全部证明或验收答案。
- **负荷**：在两小时课内预留约 35 分钟试读；这是待实测调整的预算，不能假定该范围对所有人都只需这个时间。

如果用户的主教材已经覆盖这些内容，就以其对应范围为主；此处只用来示范如何定位和提问。

## 补充应说明什么

连续性刻画局部误差控制：指定输出误差上限后，能否用足够小的输入邻域保证它。对 f:D⊆ℝ→ℝ 与 a∈D，要求每个 ε>0 都存在 δ>0，使所有满足 |x−a|<δ 的 x∈D 都有 |f(x)−f(a)|<ε。δ 可依赖 ε 和固定点 a，不能再随待检查的 x 改变。

数列判别把这一局部控制与极限工具接起来；在实数或度量空间中它与连续性等价。写成“函数极限等于函数值”时要补上 a 是定义域聚点的条件；孤立点应直接按连续性定义处理。这两种表述的条件不能省略。[来源：定义 3.2.1、命题 3.2.2](https://www.jirka.org/ra/html/sec_cont.html)

有需要时用 f(x)=x² 在不同定义域上的行为说明“局部控制”和“全域统一控制”的差别，保留同一主题的数学例子。补讲可以展示一个不同于验收题的局部估计，解释为什么先限制邻域再控制乘积；之后让用户自己做变式。

## 领域位置与逻辑关系

全局学习位置可先按“实数结构 → 数列/函数极限 → 连续性 → 微分与积分 → 函数列与极限交换”定位；这是一条阅读路线示意，不把所有箭头解释成定理依赖。当前展开连续性，后续分支等基础具备后再深入。
下面是概念与定理关系，不是要求新手一次学完的章节顺序。“后续”节点只用于定位，当前评估只覆盖已经安排学习的内容。

~~~mermaid
flowchart TD
    Q["量词、绝对值与邻域"] -->|"用于表述"| C["点连续：ε–δ"]
    S["数列收敛"] -->|"提供证明工具"| E["序列判别"]
    C <-->|"等价：实数/度量空间"| E
    C -->|"四则/复合：核对定义域及分母非零"| O["构造新的连续函数"]
    C -->|"后续：加紧致定义域"| U["一致连续"]
    C -->|"后续：加非空紧致定义域，实值"| M["取得最大值和最小值"]
    C -->|"后续：加连通定义域，实值"| I["介值性质"]
~~~

“为什么继续构建”：点连续给局部控制；一致连续讨论能否对整个定义域采用同一个 δ；最值与介值结论分别借助紧致性与连通性把局部性质转成整体信息。不能把“最值”画成“介值”的前提，也不能把“紧致”当成“连通”。

在实数闭区间上，连续推出一致连续；Lebl §3.4 的证明使用 Bolzano–Weierstrass，不需要先把极值定理当作前提。更抽象的“开集原像开”表述待具备度量空间基础后再加入，不能把“像开”当作同一结论。[§3.4](https://www.jirka.org/ra/html/sec_unifcont.html)；[§7.5](https://www.jirka.org/ra/html/sec_metcont.html)

这些基础概念有明确边界：一致连续蕴含连续，反向一般不成立；结论必须随定义域一起判断。连续性的定义本身不需要先证明所有紧致性定理。

## 图与教材对照怎么用

若用户卡在量词含义，可用 ε 带与 δ 邻域图；若卡在“一套 δ 是否适用于所有位置”，可以制作 x² 的交互图，调整 a、ε 与定义域。先提出预测问题，再观察图像并回到不等式。单一窗口或有限采样不能证明全域一致连续。

这份示例只核对了同一教材的不同章节，不冒充多本教材的实质比较。正式选定第二本书后，按下面的维度核对正文，再决定补读哪段：

| 比较项 | 要回答的问题 |
| --- | --- |
| 定义与位置 | 是直接用 ε–δ，还是先用极限？聚点、孤立点怎样处理？ |
| 条件与结论 | 定义域相同吗？在讨论点连续、整个集合上连续，还是一致连续？ |
| 证明路线 | 用数列、紧致性还是其他工具？所需前置是否已学？ |
| 当前用途 | 哪一段恰好解释当前卡点？其余内容能否暂不读？ |

## 读后评估与进度调整

不要只问“懂了吗”。按当前阶段选一个问题，等真实回答再决定下一题：

- **概念**：准确说出 δ 的依赖关系，并说明换一组量词为何可能改变命题。
- **论证**：解释读过证明中的关键前提；随后用未见函数或条件做一道独立变式。
- **迁移**：学习到相应定理后，改变定义域并判断能否保证最值、介值或一致连续，用依据或反例支持判断。

允许的资料和评价标准在任务开始前说明。关键定义/推理缺口触发定向补强；只在提示后做对则记录辅助完成；关键目标独立通过后推进，并把跨天混合复测放入后续预算。不要在练习卡中同时放出验收答案，也不要把读过的证明原样复现当成迁移能力。
