# 语言课程：先能完成交流任务，再逐步扩展

## 目标与起点

先确认用途（旅行、日常交流、阅读、工作/留学或考试）、接触程度、其他语言基础、每周投入以及能否听音频/提交语音。已有答案不重问。零基础不等于必须通过陌生语法测试；可以确认识字/语音接触，再进入一个很小的入门任务。

用 CEFR 等可靠框架描述“能做什么”，按听、读、口语互动、口语表达、写作分别设目标。整体级别只能是有范围说明的教学估计；没有标准化证据时不能声称已获得认证或完整达到某一级。不要凭语言名称就固定总学时，先约定目标情境和所需维度。

## 教材与课次

选适合自学、带音频及练习反馈的主教材；核对适用母语、版次和音频获取方式。语言课程仍以教材的累积结构为主线，情境任务、分级听读补充真实使用。已核实的公开课程可作为等候取得教材期间的起步资源，不把需要教师引导的课堂教材自动视为可独立自学。

阶段按照交际任务组织，例如问候与基本信息 → 日常需求与简单问答 → 叙述经历和安排 → 解释观点。这里只是可能的方向，按目标重排；“掌握自我介绍”不等于完成 A1。

两小时中安排听读输入、必要语言点、口头/书面提取、交流任务和复盘。将词汇、搭配、语音与语法放进可用语境。课间短听读/复习适合分散安排，但要计入用户预算。不要把所有时间用于语法讲解、单词翻译或无反馈闲聊。

## 单元运行

1. 给一个可理解的短对话或片段，说明情境和目标。
2. 教本单元必要的表达、音义关系和语法，回应具体问题。对重点提供清楚示范，随后撤除支撑。
3. 让用户自己回忆、组合和表达；口语任务尽量维持连续交流，结束后优先纠正影响理解或与本课目标相关的错误。
4. 用新人物信息、不同顺序、信息差或一个追问检验。练过的句子原样背出只支持该次复现，不能直接证明临场互动。
5. 下一课用短任务复测旧表达，把反复出错的点插回课程，逐渐扩大表达范围。

## 模态与证据边界

| 观察到的材料 | 可以判断 | 不能据此判断 |
| --- | --- | --- |
| 文字阅读与回答 | 阅读理解及相应知识 | 听力和发音 |
| 文字写作/文字角色扮演 | 书面组织与表达 | 流利口语、口头互动 |
| 新音频后的实际回答，未先看文本 | 对该材料的听力理解；注明播放次数/字幕/翻译 | 未测场景中的全部听力能力 |
| 可实际分析的原始语音 | 本次表达的内容及能够可靠观察的发音特征 | 没有发生过的实时互动 |
| 只有语音转录 | 转录中的语言内容，且可能受识别错误影响 | 音素、重音和韵律是否正确 |
| 用户自报完成外部练习 | 已自报练习 | 直接验证的分项掌握 |

教练没有音频访问/分析能力时直说，将对应维度记“未测”，提供已核对的外部听力活动及作答方式，或待语音条件具备后补测。不能从法语拼写、音标或用户说“读了”推断发音通过。

听力测验先播放/提供真实音频，再回答；转录与答案在作答后提供。使用合成语音时标明来源和局限，不冒充母语者原声。保留训练的认知挑战，不以隐藏必要任务说明制造困难。
