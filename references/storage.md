# 统一学习目录

每次进入课程先按以下顺序定位，不因聊天或工作目录变化而新建重复课程：

1. 用户在当前请求中明确给出的课程目录或状态文件。单次显式路径不自动迁移其他课程。
2. 本 Skill 安装目录下的 `references/storage.local.md`（若存在）中记录的统一学习目录。
3. 当前用户主目录下的 `Self-Study`。将 `~` 解析成实际主目录；Windows 使用当前用户的主目录，不能把字符串 `~/Self-Study` 原样当成相对路径。

在首次使用默认位置时告知实际解析后的目录。用户已指定位置就沿用，不反复确认；只有路径含糊、冲突或权限确实不足时才澄清。始终按实际文件权限执行，不能因默认路径存在就假定有写入权限。

用户明确设置新的统一目录时，在 `references/storage.local.md` 记录真实绝对路径与简短说明。该文件已列入 `.gitignore`，不向发布仓库提交私人路径。不要修改通用 `storage.md` 来保存个人设置，不擅自迁移旧课程。若无法写入本地配置，说明未保存，并让用户在下一次对话提供课程路径。

- 总索引：统一目录下的 `INDEX.md`。
- 课程目录：`courses/<course-id>/`，例如 `courses/french-daily/`。
- 每门课程：`STATE.md`、`ROADMAP.md`、`SESSIONS.md`，必要时加 `work/` 存练习。
- 学习目录放在 Skill 和发布仓库之外。从索引定位课程，不扫描磁盘上的其他笔记或完整聊天。
- “继续法语”且只有一个相关档案时，直接读取；多个目标不同的法语课程时，展示课程名让用户选择，不合并进度。
- 缺少文件权限时说明具体路径并按环境流程请求访问；不能保存时继续可完成的教学，交付可复制的续学状态，不声称已经保存。

换机器时备份学习目录与本地配置，在新环境中调整真实路径；不要把另一台机器的主目录路径当成当前可访问目录。
