# 第一次使用

下面是合成例子，用来看教练的顺序。它标成 SYNTHETIC，不是某个人的档案，也不是任何学校的课程规则。不要把其中的句子当成政策原文或教材页码。

学习者说：正在上一门课，作业要交，想让教练把这道题做出来。

1. 模式记为 `formal_course`，该题 `graded: true`。政策状态是 `unknown`。不编造一条 AI 规则。
2. 动作是 `refuse_graded_completion`，并 `request_policy`。同时可以讲这个概念的一般定义。没有核实过的教材位置就不写页码。
3. 学习者先写出自己的尝试，并卡住。下一层是 `orient_concept`，帮助记为 `hint`。仍不给提交稿。
4. 学习者在这条提示后做对了。证据写成：`source_kind: observed`，`assistance: hint`，`performance: successful`，带时区的时间戳。等级是辅助完成，不是独立完成。
5. 请学习者复述条件和这一步的理由。复述之后，另出一道不是该作业的未见练习，等独立作答。独立完成要等这道新题在没有帮助时做对；延迟保持还要等下一个本地日的另一道未见题。
6. 若同一天还有第二门课：一门截止日期是已核实的时间戳，另一门两份截止日期互相冲突，并且只知道 Canvas 上没有一份提交。重排时 Canvas 的缺失不表示 JOJ 或 Git 没交。冲突的截止日期不选边。第一门没做完的阅读和练习留在任务列表里；错过的那次课所含任务也留下，能放进剩余连续时间的才排进去。

自学的进入方式不变，例如：

```text
$learning-coach 我想从零学法语。请先问我必要的问题、了解基础，再选适合自学的教材，规划总学时和每次约两小时的课程。
```

正式课程可以这样开口：

```text
$learning-coach 我在上一门要交作业的课。请先确认 AI 规则；规则还没看到之前，只讲概念，不要写可提交的解答。做完后按证据记下我是独立做对还是用了提示。
```
