# 学习档案与跨对话续接

## 文件职责

| 文件 | 内容 | 读取时机 |
| --- | --- | --- |
| `INDEX.md` | 课程 ID、名称/目标、状态文件的相对路径、最近活动 | 找课程时 |
| `STATE.md` | 当前阶段/课次/环节、能力证据、待答题、复测和下一步 | 每次开始与继续 |
| `ROADMAP.md` | 学习范围、先修关系、教材选择、总学时、完整课次表和资源定位 | 初建/修改计划/进入课次 |
| `SESSIONS.md` | 按时间追加的简短教学与验收记录，引用练习文件 | 需要追溯判断时只读相关部分 |

使用 UTF-8 Markdown，普通文件即可迁移，不依赖聊天记忆、数据库或付费应用。

## 创建与恢复

新课程先建立最小 `STATE.md`，把还在等待的入门问题记下来；诊断完成后补齐路线。不要为“制作 Skill”或纯方法讨论创建虚构学习记录。

课程 ID 用简短稳定名称；已有同名目录时先读内容判断是否同一目标。写入只影响该课程与索引对应行，保留其他课程和用户改动。恢复时先以实际文件和最新明确的用户陈述对照；记录冲突则指出具体差异，保留已验证证据，不能默默清空或把自报改成实测。

当前状态保持简短，详细历史留在 `SESSIONS.md`。先记录本轮证据，再更新状态，最后更新索引；写后读回关键字段。部分写入失败时明确哪些已写、哪些未写，下一轮先核对，不宣称全部保存成功。

## STATE.md 必需字段

以下是字段契约，不需要机械输出空栏：

- 课程 ID / 名称 / 路线版本 / 更新时间（含时区）。
- 学习目标与验收情境；已知基础与来源（自报/诊断），每周时间、偏好和使用条件。未回答的标“待确认”。
- 当前阶段、课次、环节：了解需求 / 诊断 / 规划 / 教学 / 练习 / 验收 / 复测。
- 本次学到了哪里：教材/资源 ID 与章节，最近一个已经教完的内容。
- 课次状态：待开始 / 进行中 / 已完成教学与练习 / 已验收；与能力掌握分开记录。
- 能力表：目标或技能、当前证据等级、任务/记录 ID、日期、允许辅助及主要缺口。
- 待答问题：保留具体题干、已给提示、用户已提交到哪里；如果没有写“无”。
- 待复测：技能、原因、建议日期/间隔、届时任务类型。没有调度工具时这是安排，不是已创建提醒。
- 下一步：可以直接执行的一个动作及是否正在等待用户。
- 时间：计划课次/课内总时长/另计练习；本课已完成部分、剩余部分；实际时间仅记录用户报告或可靠计时，并注明来源。

证据等级：

| 等级 | 需要的证据 |
| --- | --- |
| 未测 | 尚未获得相应任务证据；无条件测时也保持未测 |
| 已接触 | 已教学/看过示例，尚无独立表现 |
| 辅助完成 | 用过提示、答案、翻译、字幕或其他足以影响判定的帮助 |
| 独立完成 | 在事先约定的允许资源下独立完成未见任务；注明例如“可查 API 文档、无 AI 解答” |
| 延迟保持 | 跨天的独立复测通过；注明日期与任务，不能由同一课的重复题推断 |

诊断“自报会”不是独立完成。新错误不会抹掉历史成绩，应更新当前薄弱点与复测安排。不能用这些等级计算未经定义的能力百分比；展示已验收课次、核心目标证据和仍未测的维度。

## ROADMAP.md 必需内容

1. 本轮终点与实际用途，学习范围及暂后置内容；目标改变时更新版本。
2. 一张简短领域/先修地图，解释重要内容优先的依据。
3. 教材选择：主教材的书名/作者/版次/适用基础/选择理由/获取方式及已核对范围；辅助教材解决的具体缺口。
4. 时间预算：排定 N 课、每课约 2 小时、课内合计、课间投入、可能的补强课与总投入区间，明确包含休息与否。估算以目标和诊断为依据，不写保过或必达承诺。
5. 阶段表：阶段 ID、能完成的任务、关键先修、课次范围、验收标准。
6. 课次表：每课都有具体内容、练习/独立验收、资源位置、复盘/复测重点。为当前课给出约 120 分钟分配；可拆为多次学习。
7. 资源表：稳定 ID、书名/机构、链接或授权文件路径、版次/章节/页码或活动标题、难度和用途、访问条件、核查日期和验证程度。不同版本不能编造共用页码；尚未拿到正文时用已核对目录定位并说明。

每课资源优先定位到具体章节/活动，不只给网站首页。规划阶段可保留已确认教材的章节定位；正式使用前核实题目或活动内容。资源搜索与验证由教练承担，付费/登录障碍须明确并准备可行替代。

## SESSIONS.md 的最小记录

每次有实质教学或作答后追加：日期和课次 → 教过什么 → 任务与材料位置 → 用户表现摘要 → 使用了什么帮助 → 反馈与判断 → 下次行动。只保留支持判断的短片段或练习文件链接，不复制完整聊天、整本书或原始录音。

阶段验收要覆盖此前定义的核心目标，报告“哪些通过、哪些需补强、哪些未测”。有证据的维度可以先推进；未测维度仍留在本阶段待验证。遇到用户主动跳级，记录其选择与尚缺证据，不把选择写成掌握。

## 文件不可用时

继续能做的教学，并给出可复制的简短续学记录，包含课程、阶段/课次、最新证据、未答题、下一步和待保存内容。明确“本轮尚未保存到统一目录”。下次取得文件访问后先与现有状态合并；绝不凭文件名或上一条“已保存”的说法推断磁盘内容。
