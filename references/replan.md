# 多门课的优先级与重排

一门课的路线仍按原来的课次和约两小时预算写在 `ROADMAP.md`。本文件只处理多门课抢同一段时间、以及一次错过的课怎么接上。它不把任务标成掌握，不新增提醒。

## 输入里未知和冲突保持原样

每门课分开记录：

- `deadline_status`：`known`、`unknown` 或 `conflicting`。`known` 必须带带时区的时间戳。写成“明天”这类无法解析的值时，改记未知，并丢掉这串文字，不另编一个日期。
- `deadline_reports`：只在冲突时保留各方原文，不挑选其中一个来排期。
- `signals.canvas`、`signals.joj`、`signals.git`：各自是 `submitted`、`missing`、`unknown` 或 `conflicting`。没给的系统是未知，不是缺失。Canvas 缺失不能写成 JOJ 或 Git 没交；Git 已交也不能写成 Canvas 已交。两份报告不一致就标冲突。
- `policy_status`：没有政策原文时保持未知。重排不编造政策。
- `blocks`：连续可用时间。字段缺失是 `schedule_unknown`。空列表是 `no_available_block`。区间重叠或起止无效是 `block_conflict`，不把重叠时间加在一起。

## 排序

1. 有确定截止日期的课，截止更早的在前。
2. 截止日期未知的课。
3. 截止日期互相冲突的课。

同一档里，被缺口挡住的任务更多的在前，然后是必做未完成任务更多的。未知不会被排成“已经过期”，冲突也不会被排成某一个日期。

## 放进时间块

按上面的顺序放任务，并保持任务原来的先后。一块不够就切出已经放进的分钟，剩下的分钟留在未完成列表，理由是 `partial_block`。放不下的整题留下，理由是 `no_fitting_block`。没有可用时间时，全部留下，不删。

提交类任务在截止日期未知或冲突时不排进时间块，分别留下并注明 `deadline_unknown` 或 `deadline_conflict`。其余阅读、练习和缺口学习仍可排。

某题标了 `blocked_by_gap`，且该缺口的等级还不是独立完成或延迟保持：先排一段缺口学习。只有输入里写了整数 `gap_minutes` 才使用这个时长。没写时长就不编一个默认分钟数，缺口和被挡住的题都留下。

## 错过的课

`missed_session` 记下课程、时间和未完成的 `task_ids`。重排时这些题必须还在：已经出现在任务列表里的保留，调用方漏掉的补回未完成列表。能放进剩余时间块的就排进去，放不下的继续留着。不把错过写成这些任务已经结束，也不从路线里删掉它们。

输出里的 `mastery_updates` 保持为空，`completed` 保持 false。把任务放进时间块不是把任务做完，掌握只通过证据记录改变。
