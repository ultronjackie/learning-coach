# 可携带的证据记录

掌握等级仍是这五级，不新增等级，也不把等级折成百分比：

| 等级 | 何时可以写入 |
| --- | --- |
| 未测 | 还没有相应的观察 |
| 已接触 | 教过、看过例子，或只有自报；也包括未带帮助做对了原题、但还没有未见迁移 |
| 辅助完成 | 观察到的成功发生在提示、范例、答案或其他会影响判断的帮助之后 |
| 独立完成 | 观察到的、没有帮助的成功，并且是一道未见过的迁移题；时间戳带时区 |
| 延迟保持 | 在一次合格的独立完成之后，于更后的本地日历日，用另一道未见迁移题再次独立做对 |

提示后做对、看完解答后做对、同一题刚订正，都停在辅助完成或更低，不能写成独立完成或延迟保持。自报成功最高写到已接触，不能改记成观察到的掌握。

## 一条记录

档案里可以追加 `EVIDENCE.jsonl`，每行一个对象。没有这个文件的旧课程仍然有效。`STATE.md` 里的能力表是给人读的投影，等级必须来自下面的判定，不能另起一个标准。

```yaml
schema: learning-coach.evidence/v1
skill: 要判断的能力
source_kind: self_report | observed
timestamp: 2026-11-16T10:00:00+08:00
assistance: none | hint | worked_example | answer_shown | external
performance: successful | unsuccessful | attempted
seen_before: true | false
transfer: true | false
task_id: 稳定题号
prior_independent: 上一份已经成立的独立记录，或空
```

判定规则：

1. 缺 `source_kind`、`assistance` 或 `performance`：保持未测。
2. `self_report`：成功只到已接触；不成功保持未测。
3. 观察到了但没有成功：教过或给过帮助则已接触，否则未测。
4. 观察到成功，且帮助不是 `none`：辅助完成。到此停止，不再看是不是迁移题、是不是第二天。
5. 没有帮助的成功，但缺带时区的时间戳：已接触。
6. 没有帮助的成功，但不是“没见过且是迁移题”：已接触，并记下曾经独立做对原题。
7. 没有帮助的未见迁移成功：独立完成。
8. 第 7 条再加一条合格的先前独立记录、不同的 `task_id`、以及更后的本地日期：延迟保持。同一本地日、同一题、先前只是提示成功，都达不到延迟保持。

本地日期用各自时间戳上的时区，不先换算成另一天。没有时区的时间不能支撑独立完成或延迟保持。

先前记录如果自己只是提示成功，不能拿来打开延迟保持。旧档案里只写了“独立完成”五个字、没有上述字段的，也不能当作新的先前独立记录；它仍然留在能力表里，见 [状态接口](state-interface.md)。

帮助程度从 [辅导步骤](tutoring.md) 的 `assistance` 原样抄过来。辅导动作本身不算掌握。
