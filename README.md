# learning-coach：分阶段学习教练

A textbook-grounded learning coach for Codex: diagnose, plan, teach, practise, assess, and resume across chats.

你提出一个领域，教练了解用途与基础，筛选教材和资源，估算总学时，安排每次约两小时的课程。每阶段先教、答疑，再通过你的实际作答判断是否需要补强或可以推进；换对话后从文件中的进度继续。

> Maximize struggle in the material itself. Minimize struggle in logistics: planning, finding resources, verifying, sequencing.

你承担思考和练习。教练承担查资料、排顺序、核对反馈和维护进度。挑战来自学习内容，不来自课程管理。

## 安装

在 Codex 中使用内置安装器：

```text
$skill-installer 从 https://github.com/ultronjackie/learning-coach 安装 learning-coach；SKILL.md 位于仓库根目录。
```

安装器会使用当前环境的个人 Skill 目录。也可以把整个仓库作为名为 `learning-coach` 的文件夹，放进当前 Codex 支持的 Skill 目录；不要只复制 `SKILL.md`，还需要 `references/` 和 `agents/`。目录与发现规则见 [OpenAI 官方说明](https://learn.chatgpt.com/docs/build-skills)。若同名 Skill 已存在，先保留本地配置，再合并更新。

这是供 AI 读取的 Skill，无需部署网站或购买独立服务。查找新资源需要可用的联网工具；跨对话续学需要文件读写权限；听力与发音评估需要对应音频能力。缺少某种能力时会说明实际限制。

## 开始使用

在可加载个人 Skill 的 Codex 对话中输入：

```text
$learning-coach 我想从零学法语。请先问我必要的问题、了解基础，再选适合自学的教材，规划总学时和每次约两小时的课程。
```

不需要先写完整需求。如果你暂时不知道学习目标，教练会先介绍领域结构，并给几个具体终点供选择。第一次通常先问少量关键问题，随后诊断、选资源和规划；不会一口气输出整门课程或直接给你做一场陌生知识考试。

你也可以一次提供更多条件：

```text
$learning-coach 我想学线性代数中的向量空间、线性映射和特征值。
目标是能做大学课程题，并理解它们在数据处理中的含义。
每周能学约4小时。我有这本教材，请以它为主线，重要内容先学。
先诊断基础，再告诉我需要多少课、总共约多少小时。
```

如果当前对话尚未显示新安装的 Skill，先在新对话中输入 `$learning-coach` 或从 Skill 选择器选择。也可直接提供本目录 `SKILL.md` 的绝对路径要求读取。安装文件存在不代表所有客户端都已经刷新列表。

## 课程长什么样

第一版路线会包含：

- 这轮学习的具体终点、领域结构及先修关系。
- 一本主教材，以及有明确用途的辅助教材/资源；说明版本、难度、选择理由和核对范围。
- 重要内容为什么先学、哪些内容后置。
- 排定多少课、每课约两小时、课内总学时、另计的课间练习和可能调整范围。
- 每课的内容、练习、资源章节/活动、复盘和验收方式。

总学时是以目标和诊断为基础的计划预算，不是固定时间内必然达标的保证。举例：排定 12 课 × 2 小时 = 24 小时课内投入，另有 4 小时课间复习，则当前预算为 28 小时；这是计算示例，不是法语或线代的学习时长承诺。

两小时可以这样分配：10 分钟回忆旧知识、20 分钟教学示范、40 分钟针对性练习、10 分钟休息、25 分钟变式/情境任务、15 分钟复盘。会按学科和你的表现调整，也可以拆成两次一小时或更多次聊天。

每次上课先说明当前位置与目标，再教一块内容。你可以随时追问。练习时默认把关键推导和选择留给你；需要帮助可以说“只给我一个提示”“补讲这个前置知识”或“示范一个类似题”。

## 继续、查看、调整

```text
$learning-coach 继续法语，从上次停下的地方开始。
$learning-coach 今天只有30分钟，继续当前课，不开启整节新课。
$learning-coach 展示我的课程路线、剩余课次和未验证的能力。
$learning-coach 给当前阶段做一次验收，先不要给答案。
$learning-coach 我想提前进入下一阶段，请保留薄弱项并安排补测。
$learning-coach 我一周只能学2小时了，按现有进度重新排课。
$learning-coach 今天结束，保存学到的位置和下次要做的任务。
```

无需每次复述所有背景，也不需要另开一个聊天才算进入下一阶段。新对话、旧对话都先查同一份学习档案。

## 统一学习档案

默认使用当前用户主目录下的 `Self-Study`，即 `~/Self-Study`；`~` 在使用时解析为实际主目录，不是仓库目录。所有课程共用这个入口，每门课程单独建档。

第一次也可以指定位置：

```text
$learning-coach 把统一学习目录设为我指定的完整路径，然后开始学习。
```

教练会将你提供的真实路径保存在安装目录的 `references/storage.local.md` 中。此文件已被 Git 忽略；它只用于定位学习目录，不保存练习记录。优先使用本次明确指定的课程路径，其次是这个本地设置，最后是默认位置。详见 [存储位置规则](references/storage.md)。

```text
Self-Study/
  INDEX.md
  courses/
    french-daily/
      STATE.md
      ROADMAP.md
      SESSIONS.md
      work/          有练习文件时再创建
```

- `INDEX.md`：课程索引，跨项目定位课程。
- `STATE.md`：当前阶段、课次、待答题、掌握证据和下一步。
- `ROADMAP.md`：教材、资源、完整课次与学时预算。
- `SESSIONS.md`：精简的教学、作答、反馈和复测记录。

每门课单独保存；同一学科不同目标可以有不同课程。制作 Skill 本身不会创建一门假的法语课程。实际开始学习后才建立对应档案。

需要迁移时复制整个学习目录，并更新 `references/storage.local.md` 中的本地路径。学习文件放在 Skill 和发布仓库之外；更换或重新安装 Skill 前请保留该本地配置。跨设备需让新的环境能访问学习文件，不会自动云同步。

如果新对话没有相应路径访问权限，教练会说明并走当前环境的访问流程；无法保存时会给你可复制的续学记录，不会谎称已经记住或保存。

## 法语等语言怎么学

语言课程按能完成的交流任务组织，把语音、词汇搭配和语法放在语境中。主教材优先考虑适合自学、带音频和练习反馈的版本，再补分级听读与对话练习。

听、读、口语表达、口语互动和写作分别评估。文字作答能证明相应的读写表现，不能替代听力或发音证据；没有语音条件时可以继续读写，听说保留“未测”。看过字幕或完整答案的练习会注明帮助程度。

CEFR 可用于描述阶段目标，但几次聊天不会产生正式等级认证。只有你有 DELF 等考试目标时才按相应考试要求安排。法语候选入口与核查状态见 [语言参考](references/languages.md)。

## 掌握程度怎么看

记录区分“未测、已接触、辅助完成、独立完成、延迟保持”。当前阶段的关键能力通过独立任务后可以往前走，同时保留跨天复测。讲过、觉得懂了、看答案后做对，都不会自动计为独立掌握。

数学有计算、概念、反例和证明；编程有实际实现、测试、调试与需求变动。题目由教练核对，但学习结果需要由你的真实表现支持。

## 工具与边界

默认从“教材 + 本 Skill + 本地学习档案”开始，就能完成诊断、规划、逐步教学和续学。

NotebookLM 可作为选用的资料助手：围绕你选定的来源提问，并回到引用位置查看上下文；这些能力已在 [Google 官方聊天说明](https://support.google.com/gemininotebook/answer/16179559?hl=en) 核对（2026-10-23，当前文档标题为 Gemini Notebook）。适合拿来辅助读书、比较资料；其中的摘要或回答仍需对照原文，不能自动算作你已掌握的证据。你可以把相关结论和来源位置带回课程，由教练接着教学和检查。

暂时不需要先开发专门软件。实际学习中如果反复需要交互图形、代码运行练习或语音活动，再按具体瓶颈加入合适工具。Anki 等复习工具也按实际需要选择，复习任务和耗时仍纳入课程计划。

不会因为启动 Skill 就自动购买教材、上传书籍、报名考试或设置提醒。

它保存必要的学习目标、资源位置和表现摘要，不保存整段聊天或原始录音。方法依据见 [设计依据](references/basis.md)。

仓库只包含 Skill 指令与方法参考，不附带教材正文、个人学习记录或原始录音。
